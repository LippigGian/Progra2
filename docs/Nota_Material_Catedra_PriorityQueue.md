# Material de cátedra: TDA PriorityQueue

El contenido de `src/priorityQueueModule/` se incorporó como modelo/base
compartido por la cátedra para estudiar y utilizar el TDA PriorityQueue.

No corresponde a una entrega semanal desarrollada por este proyecto. Se
conserva en el repositorio porque `complaintModule`, correspondiente al TP 07,
lo utiliza mediante su interfaz `SimplePriorityQueue` y necesita estar
disponible para compilar y ejecutar la aplicación de reclamos.

El desarrollo propio del TP 07 se encuentra en `src/complaintModule/`.
